DHT22:
    VCC -> 3V3
    GND -> GND
    DAT -> D4

OLED Display:
    VCC -> 3V3
    GND -> GND
    SCL -> D1
    SDA -> D2

ADS1115 (external 16-bit I2C ADC, for the analog LDR):
    VDD  -> 3V3
    GND  -> GND
    SCL  -> D1    (shared I2C bus with the OLED)
    SDA  -> D2    (shared I2C bus with the OLED)
    ADDR -> GND   (sets I2C address 0x48)
    ALRT -> (not connected)
    A0   -> LDR divider junction (see below)
    A1   -> Suppress button   (button 1, see below)
    A2   -> Button 2          (plays 06/ in break/idle/time)
    A3   -> Button 3          (idle <-> time-state toggle)

LDR (analog, divider into ADS1115 channel A0):
    LDR Pin 1      -> 3V3
    LDR Pin 2      -> ADS1115 A0   (junction node)
    Resistor Pin 1 -> ADS1115 A0   (same junction node)
    Resistor Pin 2 -> GND

Push buttons (each: Pin 1 -> 3V3, Pin 2 -> ADS1115 AINx, plus a ~10k pull-down
from that AINx -> GND so it idles near 0):
    Button 1 (suppress)     -> ADS1115 A1
    Button 2 (play 06/)     -> ADS1115 A2
    Button 3 (time state)   -> ADS1115 A3

Potentiometer (analog, sets the timer values):
    Pin 1 (end)   -> 3V3
    Pin 2 (wiper) -> A0    // moved here from D8: A0 is the only analog input
    Pin 3 (end)   -> GND

Touch Sensor 1 (TTP223):    // Start focus timer / stop the cycle
    VCC -> 3V3
    I/O -> D7
    GND -> GND

Touch Sensor 2 (TTP223):    // Enter/cycle set mode (focus -> break -> idle)
    VCC -> 3V3
    I/O -> D6    // moved off D3 (GPIO0) which is a boot-strapping pin
    GND -> GND

Traffic-light LEDs:
    RED    -> D5   (GPIO14)
    YELLOW -> D0   (GPIO16)
    GREEN  -> D8   (GPIO15)

Alert LED (blue) -- blinks when backend reports "distracted" or "away":
    BLUE   -> D3   (GPIO0)

DFPlayer Mini (mini MP3 module):
    VCC  -> 5V (VU/VIN)   // onboard amp is weak at 3.3V; 5V is louder
    GND  -> GND
    RX   -> TX (GPIO1)    // ESP transmits commands;
    TX   -> leave UNCONNECTED
             // We only send commands. Do NOT wire module-TX -> ESP-RX while the
             // module runs at 5V: its 5V TX would over-drive the ESP's 3.3V RX.
    SPK1 -> speaker +
    SPK2 -> speaker -
