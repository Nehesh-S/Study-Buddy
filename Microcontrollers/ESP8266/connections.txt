DHT22:
    VCC -> 3V3
    GND -> GND
    DAT -> D4

OLED Display:
    VCC -> 3V3
    GND -> GND
    SCL -> D1
    SDA -> D2

LDR:
    Pin 1 -> A0
    Pin 2 -> 3V3

Resistor:
    Pin 1 -> A0
    Pin 2 -> GND

Touch Sensor 1 (TTP223):    // For starting the timer
    VCC => 3V3
    I/O -> D7
    GND -> GND
